# ProConnect - Professional Social Networking Platform

ProConnect is a comprehensive professional networking platform that combines traditional social networking features with innovative micro-project collaboration capabilities. It's designed to help professionals connect, share experiences, collaborate on projects, and grow their professional network.

## 🌟 Key Features

### 1. Professional Networking

- Create and manage professional profiles
- Connect with other professionals
- Share posts and updates
- Engage through comments and interactions
- Discover professionals based on skills and interests

### 2. Micro-Projects

- Create and manage small-scale collaborative projects
- Task management and tracking
- Real-time project chat functionality
- Mentor-mentee relationship building
- Project-based learning opportunities

### 3. Feed System

- Personalized feed based on connections and interests
- Multiple feed types for different content categories
- Engagement scoring system
- Smart content recommendations

### 4. Profile Management

- Detailed professional profiles
- Skills and interests sections
- Education and work experience tracking
- Profile picture customization
- Achievement showcase

### 5. Job Portal

- Browse job opportunities
- Job posting functionality
- Relevant job recommendations
- Easy application process

## 🔧 Technical Architecture

### Frontend (React + Vite)

- Modern React components with functional approach
- State management using atomic design patterns
- Responsive and intuitive UI
- Real-time updates and notifications

### Backend (Node.js + Express)

- RESTful API architecture
- MongoDB database integration
- Authentication middleware
- File processing services
- Cloud storage integration (Cloudinary)
- AI-powered services (Gemini)

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- MongoDB
- npm or yarn

### Installation

1. Clone the repository
   \`\`\`bash
   git clone https://github.com/theritikyadav11/ProConnect.git
   cd ProConnect
   \`\`\`

2. Install Backend Dependencies
   \`\`\`bash
   cd backend
   npm install
   \`\`\`

3. Install Frontend Dependencies
   \`\`\`bash
   cd frontend
   npm install
   \`\`\`

4. Set up environment variables
   Create .env files in both frontend and backend directories with necessary configurations.

### Running the Application

1. Start the Backend Server
   \`\`\`bash
   cd backend
   npm start
   \`\`\`

2. Start the Frontend Development Server
   \`\`\`bash
   cd frontend
   npm run dev
   \`\`\`
